# گزارش آزمون نویدشاپ ۰٫۳٫۰ — Navid Studio

تاریخ اندازه‌گیری نهایی: 2026-10-20T06:54:40.765Z

## محیط و محدوده

وردپرس 7.1.3، ووکامرس 11.2.1، PHP 8.3.33، SQLite و WordPress Playground محلی. مرورگر Chrome Headless. صحنه سه‌بعدی در بررسی عملکردی با WebGL نرم‌افزاری SwiftShader آزمایش شد؛ کارایی GPU گوشی‌ها و رایانه‌های مختلف از این بررسی قابل استنتاج نیست. آزمون هاست واقعی PHP/MySQL، پرداخت بانکی و ممیزی مستقل امنیت هنوز انجام نشده‌اند.

## آزمون‌های رفتاری

تمام **۳۷ آزمون** موفق شدند: ۱۱ آزمون خرید و رابط اصلی، ۹ آزمون تکمیلی تجربه خرید، ۱۴ آزمون Studio و ۳ آزمون مدیریت.

- محصول ساده و متغیر، دو انتخاب رنگ با شناسه متفاوت، Ajax سبد، تغییر تعداد و هماهنگی شمارنده دسترس‌پذیر.
- سفارش مهمان با پرداخت در محل آزمایشی؛ هیچ پرداخت واقعی انجام نشد. محصول ناموجود قابل خرید نبود.
- منوی موبایل، دسته‌ها، جستجوی بومی، مرتب‌سازی، حساب کاربری، صفحه ۴۰۴، مجله و رفتار بدون JavaScript.
- پیش‌نمایش سریع با داده درست، Escape، بازگشت فوکوس و رندر متن تزریقی به صورت متن.
- صحنه Three.js/WebGL واقعاً رندر شد. تغییر رنگ و چرخش با کلید، پیکسل‌های تصویر خروجی را تغییر داد.
- توقف همه حلقه‌های CSS و حفظ انتخاب توقف پس از بارگذاری مجدد.
- علاقه‌مندی پس از بارگذاری مجدد حفظ شد و قیمت/موجودی آن با API عمومی ووکامرس تازه شد.
- جدول مقایسه واقعی، حذف از مقایسه، جستجوی زنده با پیوند واقعی و خروج با Escape.
- فیلتر ترکیبی قیمت، موجودی و تخفیف، پاک‌سازی فیلتر و فیلتر دسته؛ نوار خرید و تاریخچه بازدید.
- ابزارها در موبایل، کاهش حرکت بدون دریافت مدل، خرابی داده ذخیره‌شده، رد URLهای JavaScript و متن تزریقی، و تصویر جایگزین در نبود WebGL.
- درون‌ریزی ناشناس رد شد؛ nonce نامعتبر مدیر با HTTP 403 رد شد؛ چایلدتم و حالت ووکامرس غیرفعال کار کردند.

قواعد خودکار منتخب WCAG 2/2.1 A/AA در مسیرهای ثبت‌شده مورد نقضی نداشتند. این نتیجه جای بررسی کامل دستی دسترس‌پذیری نیست. گزارش خام در `reports/` موجود است. بررسی نحوی 18 فایل PHP و فایل‌های JavaScript موفق بود.

## نمایش

عرض‌های ۳۶۰، ۳۹۰، ۷۶۸، ۱۲۰۰ و ۱۴۴۰ پیکسل بررسی شدند: بدون اسکرول افقی، تصویر خراب یا خطای JavaScript ثبت‌شده. فونت محلی وزیرمتن و ۸ کارت محصول موجود بودند. مدل سه‌بعدی در هر پنج عرض بررسی شد؛ در عرض حداکثر ۸۰۰، با دکمه دستی فعال شد. همه مرورگرها و تلفن‌ها پوشش داده نشده‌اند.

## سرعت؛ آزمایشگاه موبایل با رفتار پیش‌فرض محصول

امتیاز Lighthouse عملکرد **79**، دسترس‌پذیری **100**، بهترین رویه‌ها **100** و SEO **77** بود. CPU به ضریب ۴ و شبکه مطابق `reports/performance.json` محدود شدند. کش صفحه و فشرده‌سازی پاسخ فعال نبودند.

| معیار | نتیجه |
|---|---:|
| FCP | 1.97 ثانیه |
| LCP | 4.14 ثانیه |
| TBT | 54 میلی‌ثانیه |
| CLS | 0.000 |
| داده منتقل‌شده | 509 KiB |

در محصول پیش‌فرض، موبایل پوستر متحرک را می‌بیند و مدل با دکمه «نمای سه‌بعدی» دریافت می‌شود؛ آزمون سرعت نیز همین رفتار واقعی را سنجیده است. هزینه دریافت، کامپایل و رندر پس از فعال‌سازی دستی مدل، امتیاز جداگانه‌ای ندارد. ماژول مدل حدود ۵۶۲ KiB خام و ۱۴۳ KiB با gzip دارد؛ فشرده‌سازی باید در هاست فعال شود. مدل در صفحات پرداخت/سبد/محصول دریافت نمی‌شود. رندر با خروج از دید، زبانه پس‌زمینه یا توقف حرکت متوقف می‌شود.

این اعداد تضمین سرعت هاست یا INP واقعی نیستند. آزمون هم‌زمان کنترل‌شده‌ای با نسخه قبلی انجام نشده است.

## امنیت و عرضه

فهرست‌ها فقط شناسه عمومی محصولات را در مرورگر ذخیره می‌کنند. قیمت مرورگر در سفارش استفاده نمی‌شود؛ سبد و سفارش همچنان بومی ووکامرس هستند. ابزارها API اختصاصی، کلید دسترسی یا مجوز مدیریتی جدیدی ندارند. داده API با `textContent` نمایش داده می‌شود و URLها اعتبارسنجی می‌شوند. دامنه بررسی، آزمون نفوذ یا تضمین امنیت کامل نیست.

پیش از عرضه در راست‌چین و ژاکت: هاست واقعی، درگاه و افزونه‌های هدف، چک‌لیست جاری فروشنده، اتصال مجاز لایسنس/به‌روزرسانی و ممیزی مستقل امنیت باقی است. نسخه هنوز تأیید تجاری مارکت ندارد.
