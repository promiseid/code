# Changelog

## 0.1.0 — 2026-10-19

- Initial Persian WooCommerce theme with a responsive shopping homepage.
- Native product, cart, checkout, account, search and category integration.
- Optional local demo importer, including simple, variable and unavailable products.
- Native customizer settings, local Vazirmatn fonts and original product illustrations.
- Independent child theme and translation template.
- Cart counter synchronizes with the refreshed WooCommerce cart markup.
- Accessible mobile account/cart labels and improved text contrast.
- Homepage avoids unused classic WooCommerce styles; fonts are preloaded.
- Editable Figma desktop and mobile homepage designs.

This is the initial review release. Marketplace approval, marketplace-specific
licensing/updating, independent security review and production hosting validation
remain release steps before commercial publication.
