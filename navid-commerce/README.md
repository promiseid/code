# نویدشاپ — Navid Commerce 0.1.0

- [مشاهده آنلاین فروشگاه](https://playground.wordpress.net/?blueprint-url=https://raw.githubusercontent.com/promiseid/code/main/navid-commerce/playground/blueprint.json)
- [باز کردن پیشخوان فارسی](https://playground.wordpress.net/?blueprint-url=https://raw.githubusercontent.com/promiseid/code/main/navid-commerce/playground/admin.json)
- [راهنمای نصب، امکانات و محدودیت‌ها](./README-fa.md)
- [گزارش آزمون‌های قالب](./TEST-REPORT-fa.md)
- [راهنمای پیش‌نمایش و نگهداری تغییرات](./playground/README-fa.md)

نام کاربری دموی مرورگری: `admin` — رمز نمونه: `NavidDemo!2026`.

هر لینک یک WordPress Playground جداگانه می‌سازد. این دمو در مرورگر اجرا می‌شود و فروشگاه دائمی با پایگاه‌داده مشترک نیست. برای رفت‌وآمد بین فروشگاه و پیشخوانِ همان محیط، از نوار مدیریت وردپرس استفاده کنید. تغییرات را با امکانات ذخیره یا خروجی Playground نگه دارید.

فروشگاه و پیشخوان آنلاین، هشت محصول نمونه، فعال بودن قالب، فارسی بودن محیط، رمز نمونه و نقش مدیر در ۱۹ اکتبر ۲۰۲۶ بررسی شدند. فایل‌های دریافت‌شده از گیت‌هاب نیز با نسخه آماده‌شده تطبیق داشتند.

این نسخه هنوز تأیید تجاری راست‌چین یا ژاکت را ندارد. اطلاعات ورود دمو در فایل نصب قالب وجود ندارد و برای سایت واقعی مناسب نیست.
