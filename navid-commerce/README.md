# نویدشاپ — Navid Commerce 0.4.0

قالب فروشگاهی فارسی وردپرس و ووکامرس با چیدمان بازارگاهی، پنل اختصاصی مدیریت و افزونه همراه ورود.

- [ورود مستقیم به پنل مدیریت قالب](https://playground.wordpress.net/?blueprint-url=https://raw.githubusercontent.com/promiseid/code/main/navid-commerce/playground/admin-0.4.0.json)
- [فایل نصب قالب](navid-commerce-0.4.0.zip?raw=1) · [افزونه همراه ورود](navid-commerce-core-0.4.0.zip?raw=1)

ورود نمونه: `admin` / `NavidDemo!2026`. این اطلاعات عمومی صرفاً برای محیط مستقل آزمایشی مرورگر است. Playground هاست دائمی یا فروشگاه مشترک نیست؛ تغییرات را از خود Playground ذخیره یا خروجی بگیرید.

![نمای واقعی وردپرس](theme/navid-commerce/screenshot.png)

پنل «مدیریت نویدشاپ» در منوی پیشخوان و نوار بالای سایت، پنج بخش دارد: هویت و ظاهر، صفحه نخست و بنرها، ابزارهای فروشگاه، ورود پیشخوان، وضعیت و راهنما. تنظیمات با کنترل قابلیت کاربر، nonce و پالایش ورودی ذخیره می‌شوند. رسانه‌ها از کتابخانه اصلی وردپرس انتخاب می‌شوند.

صفحه نخست بازارگاهی شامل اسلایدر قابل مدیریت با توقف، میان‌برهای خرید، پیشنهادهای واقعی، دسته‌های تصویری، تازه‌رسیده‌ها، کاوش دسته‌ها و مجله است. چیدمان استودیو سه‌بعدی نیز از پنل قابل انتخاب است. دارایی‌ها و کد متعلق به همین پروژه‌اند؛ هویت یا دارایی دیجی‌کالا کپی نشده است.

افزونه همراه مستقل، عنوان، متن، رنگ، لوگو، پس‌زمینه و مسیر اختیاری ورود را تنظیم می‌کند. مسیر سفارشی ابتدا خاموش است؛ نام کاربری و رمز را تغییر نمی‌دهد. احراز هویت، خروج و بازیابی رمز از هسته وردپرس هستند. بازیابی از منوی تنظیمات، غیرفعال‌کردن افزونه یا ثابت مستندشده ممکن است.

علاقه‌مندی، مقایسه و تاریخچه در همین مرورگر نگه‌داری می‌شوند؛ API عمومی ووکامرس قیمت و موجودی را تازه می‌کند. جست‌وجوی زنده، فیلتر دسته/قیمت/موجودی/تخفیف، پیش‌نمایش سریع و نوار خرید واقعی موجودند. تنوع محصول، گالری، سبد، کوپن، تسویه‌حساب و سفارش‌ها بومی ووکامرس‌اند.

منابع CSS/JS ماژولارند و فایل‌های عمومی خود قالب برای هر صفحه به یک CSS و یک JS فشرده ساخته می‌شوند. فایل‌های مدیریت، ویرایشگر، ووکامرس و درگاه‌ها با سازوکار خود بارگذاری می‌شوند. مدل حجیم سه‌بعدی مستقل و اختیاری است؛ طرح بازارگاهی آن را دریافت نمی‌کند. ساخت: `tools/build-assets.mjs` با esbuild 0.28.2.

تمام زیرساخت دیجی‌کالا، چندفروشندگی، درگاه بانکی، پیامک و عملیات اختصاصی انبار و حمل در این بسته نیست. تأیید فروش راست‌چین/ژاکت، آزمون روی هاست واقعی و ممیزی مستقل امنیت هنوز انجام نشده‌اند. فیگمای ۰٫۱٫۰ سابقه اولیه است؛ کد و پیش‌نمایش ۰٫۴٫۰ مرجع فعلی‌اند.
