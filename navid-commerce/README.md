# نویدشاپ — Navid Commerce 0.2.0

نسخه جدید قالب فروشگاهی فارسی وردپرس و ووکامرس با بازطراحی صفحه نخست، فروشگاه، صفحه محصول و موبایل.

- [پیشخوان فارسی آزمایشی](https://playground.wordpress.net/?blueprint-url=https://raw.githubusercontent.com/promiseid/code/main/navid-commerce/playground/admin-0.2.0.json)
- [دانلود ZIP نصب قالب اصلی](./navid-commerce-0.2.0.zip?raw=1)
- [راهنمای نصب و تنظیمات](./README-fa.md)
- [گزارش آزمون‌ها و اندازه‌گیری سرعت](./TEST-REPORT-fa.md)

نام کاربری دمو: `admin` — رمز نمونه: `NavidDemo!2026`.

هر لینک یک وردپرس مستقل در مرورگر می‌سازد. برای رفت‌وآمد بین فروشگاه و پیشخوانِ همان محیط، از نوار مدیریت وردپرس استفاده کنید. برای نگهداری تغییرات از ذخیره یا خروجی Playground استفاده کنید. زمان آماده‌سازی اولیه Playground معیار سرعت قالب روی هاست واقعی نیست.

![طراحی نویدشاپ در وردپرس](./theme/navid-commerce/screenshot.png)

این نسخه شامل بنر استودیویی اختصاصی، منوی دسته‌ها، دسته‌بندی تصویری، تخفیف واقعی محصول، پیش‌نمایش سریع قابل استفاده با صفحه‌کلید، مجله، چیدمان تازه محصول و دسترسی سریع موبایل است. متن‌ها، تصاویر بنرها و بخش‌های اختیاری از سفارشی‌ساز وردپرس تنظیم می‌شوند. پیش‌نمایش سریع از داده عمومی همان محصول استفاده می‌کند و درخواست شبکه یا افزونه جدیدی اضافه نمی‌کند.

مسیر خرید و پردازش سفارش‌ها همچنان به ووکامرس واگذار شده است. سازنده کامل صفحات، علاقه‌مندی، مقایسه، چندفروشندگی، درگاه بانکی، پیامک و اتصال لایسنس مارکت در این نسخه پیاده نشده‌اند. این نسخه هنوز تأیید تجاری راست‌چین یا ژاکت را ندارد.

طرح فیگمای نسخه ۰٫۱٫۰ برای سابقه طراحی نگهداری شده است. مرجع طراحی تازه، کد و پیش‌نمایش نسخه ۰٫۲٫۰ است. جزئیات تصویر تولیدشده و پرامپت در [design/hero-asset.json](./design/hero-asset.json) ثبت شده است.
